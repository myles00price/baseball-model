THE ENGINE

Model version nba-0.1-team_only · production variant team-only · data through 2026-10-20 · model run WED OCT 21, 3:16 PM ET.
Each game gets an expected score for both teams from possession-based team ratings (offense and defense per 100 possessions, pace, home court, rest). The spread, total and win probability on this page are all read from that one projection, so they agree with each other. Win % uses the projected margin and its fitted uncertainty; fair ML is that win % as American odds with no margin.
