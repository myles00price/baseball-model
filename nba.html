HOW TO READ THESE TABLES

MODEL columns are this model's numbers. BOOK NO-VIG % is the average of each book's two-sided price with the margin removed. Model lean uses current (non-stale) quotes only.

THE ENGINE

Model version nba-0.1-team_only · production variant team-only · data through 2026-06-13 · model run TUE OCT 20, 8:58 PM ET.
Each game gets an expected score for both teams from possession-based team ratings (offense and defense per 100 possessions, pace, home court, rest). The spread, total and win probability on this page are all read from that one projection, so they agree with each other. Win % uses the projected margin and its fitted uncertainty; fair ML is that win % as American odds with no margin. The numbers come from team ratings only: the roster estimate below is research and context, not applied to any number on this page. No player props are shown on this page.

Every game predicted before its own result, season by season: fitted on 2016-17..2021-22, checked on 2022-23..2024-25, final test on 2025-26. Against final scores only - none - no trustworthy historical NBA odds on disk. No edge is claimed.
